# Machine-readable contracts

The JSON files in this directory are **derived artifacts**, mechanically
extracted from the frozen AXOS implementation. They are not hand-written
copies: every value is read from the live module object, so the JSON and
the source cannot silently disagree.

## Provenance

- Source: `src/axos/` (frozen AXOS implementation)
- Release: `551d559cf3489148fe8966b56376dfab6c5b909278685bd623eed0e7cef4c192`
  (see `src/axos/release_manifest.json`)
- Generated by: `tools/extract_contracts.py`
- Regenerate with: `python3 tools/extract_contracts.py` (from the repository root)

## Files

- `transitions.json` — the six state-transition graphs the gate enforces
  (`task`, `job`, `worker`, `artifact`, `approval`, `checkpoint`), plus
  the authoritative actor/state sets:
  `HUMAN_GATED_FROM` (I-17, sticky human-gated states),
  `WORK_CREATOR_ACTORS` (I-16, who may create work — never workers),
  `RECLAIM_ACTORS` (D1/R1, who may invoke lease reclaim).
  Source: `src/axos/store/transitions.py`.
- `recovery-ladder.json` — `CANONICAL_LADDER`, the single five-rung
  recovery ladder (contract section E.1) shared by R8 (records rung
  context) and R9 (owns ladder policy), plus the R9 terminal-state
  constants. Source: `src/axos/exec/policy.py`.
- `recovery-rungs.json` — R8's `_CANONICAL_RUNGS` mapping of each R8
  action (`reclaim`, `fence`, `restart`) to its canonical ladder rung,
  the R8 failure classes and action vocabulary, and the contract-normative
  escalation rule: zero authoritative progress across two consecutive
  recovery attempts is failed recovery and escalates to `r9-policy`.
  Source: `src/axos/exec/recovery.py`.

## Interpretation rules

- If a value here disagrees with `src/axos/`, the source wins; rerun the
  extractor and commit the corrected JSON.
- The JSON contains no extra entries beyond what the source modules
  define. A contract not present in the implementation is not present here.
- Human-readable documentation of these contracts lives in
  `docs/contracts/`; the prose there must agree with this directory.
