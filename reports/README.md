# Reports

This directory preserves the verification and audit evidence for the
frozen AXOS release (`551d559cf3489148fe8966b56376dfab6c5b909278685bd623eed0e7cef4c192`).
Nothing here is rewritten to look better than it was: historical
evidence stays historically accurate, including blocked proofs.

## Layout

- `audits/` — adversarial audit reports and audit-suite evidence.
- `verification/` — reproducibility and portability verification
  reports for the frozen release.
- `historical/` — phase reports and R-series evidence from the
  development timeline, preserved verbatim (design history, not current
  claims).

All dates below are as recorded in the documents themselves.
