## Status language

These documents distinguish carefully:

- **implemented** — the code exists in `src/axos/`.
- **tested** — covered by the suite in `src/axos/tests/`.
- **audited** — examined by an audit campaign; see
  `reports/historical/`.
- **verified** — independently reproduced (release identity,
  fresh-clone bootstrap).
- **blocked** — attempted and not completed; see the R14 evidence.
- **historical** — true of a past campaign, not a claim about now.
