# Schemas

This directory holds **derived documentation** of the AXOS durable
schema. It is generated by reading, not by running — the authoritative
schema is the code-first migration list in
`src/axos/store/migrations.py` (`MIGRATIONS`, currently v1 → v12).

## Provenance

- Source: `src/axos/store/migrations.py`
- Release: `551d559cf3489148fe8966b56376dfab6c5b909278685bd623eed0e7cef4c192`
- Derived by: manual reading of `migrations.py` (no runtime generation)
- Rule: if this documentation disagrees with `migrations.py`, the module
  wins; update the docs to match.

## Files

- `schema-v12.md` — the complete v12 schema: every table, its key
  columns, and its CHECK constraints, including the I-18
  zero-progress-delta rejection on `recovery_attempts`.
- `../migrations/README.md` — how migrations are applied (`open_store`
  + `migrate`), their atomicity guarantees, and the exact invocation.

## Notes

- The schema is versioned, deterministic, and code-first: there is no
  separate DDL source of truth. Migrations apply in order, are
  idempotent on re-run, and roll back fully on failure.
- A fresh database can be created from zero; an existing database
  upgrades deterministically to v12.
- The `schema_migrations` table (in the database itself) records which
  versions have been applied.
